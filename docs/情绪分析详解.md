## 🔍 第 2 步：逐条分词

### 分词原理

使用 **jieba 分词** 或 **SnowNLP 分词**，将句子拆分成词语。

**示例：**

```
原文：政策利好，深信服所在行业迎来发展机遇

分词：政策 / 利好 / ， / 深信服 / 所在 / 行业 / 迎来 / 发展 / 机遇
```

### 为什么要分词？

1. **识别关键词** - 找出积极/消极词汇
2. **理解语义** - 判断是褒义还是贬义
3. **准确打分** - 基于词汇的情感倾向

---

## 🔍 第 3 步：情感打分 (核心)

### SnowNLP 工作原理

SnowNLP 使用**贝叶斯分类器**，基于大量训练数据学习情感模式。

```
输入：分词后的文本
      ↓
特征提取：词汇、词性、语法结构
      ↓
分类器：对比已知的情感模式
      ↓
输出：0-1 之间的情感得分
```

### 得分含义

| 得分范围 | 情感 | 颜色标识 |
|---------|------|---------|
| 0.0 - 0.4 | 负面 | 🔴 红色 |
| 0.4 - 0.6 | 中性 | ⚪ 灰色 |
| 0.6 - 1.0 | 正面 | 🟢 绿色 |

### 打分示例

```python
新闻标题："政策利好，深信服所在行业迎来发展机遇"

分析过程:
1. 分词：政策/利好/深信服/行业/迎来/发展/机遇
2. 识别情感词：利好 (积极)、发展 (积极)、机遇 (积极)
3. SnowNLP 打分：0.864
4. 判断：0.864 > 0.6 → 正面
```

### 输出示例

```
1. 🟢 新闻标题：政策利好，深信服所在行业迎来发展机遇
   情感得分：0.864
   情感分类：正面
   积极词汇：利好，发展 → 推高分数
   分析原因：得分>0.6，表达积极情感
```

## 🔍 第 4 步：情感分类

### 分类标准

```python
if score > 0.6:
    sentiment = '正面'
    reason = "得分>0.6，表达积极情感"
elif score < 0.4:
    sentiment = '负面'
    reason = "得分<0.4，表达消极情感"
else:
    sentiment = '中性'
    reason = "得分在 0.4-0.6 之间，情感不明显"
```

### 完整分析示例

```
新闻 1: "深信服新产品获得市场认可，订单爆满"
├─ 分词：深信服/新/产品/获得/市场/认可/，/订单/爆满
├─ 情感词：认可 (积极)、爆满 (积极)
├─ SnowNLP 得分：0.507
├─ 分类判断：0.4 < 0.507 < 0.6 → 中性
└─ 输出:
   情感得分：0.507
   情感分类：中性
   分析原因：得分在 0.4-0.6 之间，情感不明显

新闻 2: "深信服业绩不及预期，股价承压"
├─ 分词：深信服/业绩/不及预期/，/股价/承压
├─ 情感词：不及预期 (消极)、承压 (消极)
├─ SnowNLP 得分：0.156
├─ 分类判断：0.156 < 0.4 → 负面
└─ 输出:
   情感得分：0.156
   情感分类：负面
   消极词汇：不及预期，承压 → 拉低分数
   分析原因：得分<0.4，表达消极情感
```

## 🔍 第 5 步：汇总整体情绪指数

### 整体得分计算

```python
整体得分 = (新闻 1 得分 + 新闻 2 得分 + ... + 新闻 N 得分) ÷ N

示例:
新闻 1: 0.864 (正面)
新闻 2: 0.507 (中性)
新闻 3: 0.156 (负面)
新闻 4: 0.732 (正面)
新闻 5: 0.423 (中性)

整体得分 = (0.864 + 0.507 + 0.156 + 0.732 + 0.423) ÷ 5
         = 2.682 ÷ 5
         = 0.536

判断：0.45 < 0.536 < 0.55 → 中性
```

### 情绪等级判断

| 整体得分范围 | 情绪等级 | 说明 |
|------------|---------|------|
| > 0.7 | 非常乐观 | 绝大多数新闻都是正面的 |
| 0.55 - 0.7 | 谨慎乐观 | 正面新闻多于负面新闻 |
| 0.45 - 0.55 | 中性 | 正面和负面新闻相当 |
| 0.3 - 0.45 | 谨慎悲观 | 负面新闻多于正面新闻 |
| < 0.3 | 非常悲观 | 绝大多数新闻都是负面的 |

### 情绪趋势判断

```python
if 正面新闻数量 > 负面新闻数量 × 1.5:
    trend = '乐观'
elif 负面新闻数量 > 正面新闻数量 × 1.5:
    trend = '悲观'
else:
    trend = '平稳'
```

### 完整汇总示例

```
【整体情绪指数计算过程】

1️⃣ 统计数据:
   - 总新闻数：11 条
   - 正面新闻：5 条 (45.5%)
   - 中性新闻：4 条 (36.4%)
   - 负面新闻：2 条 (18.2%)

2️⃣ 计算平均分:
   整体得分 = 所有新闻情感得分的总和 ÷ 新闻总数
   整体得分 = 6.012 ÷ 11
   整体得分 = 0.547

3️⃣ 判断情绪等级:
   - 中性
   - 原因：得分 0.547 在 0.45-0.55 之间，正面和负面新闻相当

4️⃣ 判断情绪趋势:
   - 平稳
   - 原因：正面 (5) 和负面 (2) 新闻数量相近

5️⃣ 投资建议:
   ⚪ 情绪中性，方向不明，建议观望
```

## 💡 如何使用这些信息

### 场景 1: 准备买入

```
如果情绪指数显示"非常悲观" (<0.3):
→ 可能是买入机会 (别人恐惧我贪婪)
→ 但要等技术面确认
```

### 场景 2: 准备卖出

```
如果情绪指数显示"非常乐观" (>0.7):
→ 可能是阶段性高点
→ 考虑减仓止盈
```

### 场景 3: 持仓观望

```
如果情绪指数"中性" (0.45-0.55):
→ 方向不明，继续持有
→ 等待更明确的信号
```

### 场景 4: 发现异常

```
如果某条新闻得分异常:
→ 查看具体词汇分析
→ 判断是否是误判
→ 人工调整权重
```

## ⚠️ 注意事项

### 1. 误判情况

**例 1: 反讽句**
```
"这业绩真是好得不得了！" (实际是讽刺业绩差)
→ SnowNLP 可能误判为正面
```

**例 2: 双重否定**
```
"不是没有机会" (实际是有机会)
→ 可能误判为负面
```

**例 3: 专业术语**
```
"市盈率破净" (实际是便宜的好事)
→ 可能误判为负面 (因为有"破"字)
```

### 2. 改进方法

1. **人工复核** - 特别关注极端得分
2. **增加上下文** - 不只分析标题，分析全文
3. **自定义词库** - 添加金融领域专用词汇
4. **结合其他指标** - 不单独依赖情绪分析

## 📚 技术细节 (可选阅读)

### SnowNLP 训练原理

1. **训练数据**: 大量标注情感的中文文本 (电商评价、新闻等)
2. **特征提取**: 词汇、词性、语法结构
3. **模型**: 朴素贝叶斯分类器
4. **输出**: 情感概率 (0-1)

### 贝叶斯公式

```
P(正面|文本) = P(文本 | 正面) × P(正面) ÷ P(文本)

P(负面|文本) = P(文本 | 负面) × P(负面) ÷ P(文本)

情感得分 = P(正面|文本)
```

### 为什么用 0.4 和 0.6 作为阈值？

这是经验值，平衡了:
- **准确率**: 阈值太宽会混入中性内容
- **召回率**: 阈值太严会漏掉边缘内容

可以根据具体场景调整。
