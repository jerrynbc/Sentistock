# 时间加权情绪分析指南

> 版本：v1.0 | 更新时间：2026-05-10

---

## 🎯 为什么需要时间加权？

### 问题：传统情绪分析的缺陷

传统方法把所有消息**平等对待**，但这不符合实际：

```
❌ 传统方法:
消息 1 (今天): "公司裁员"    权重 = 1
消息 2 (30 天前): "产品大卖" 权重 = 1
→ 平均 = (负面 + 正面) / 2

但实际影响:
今天的裁员消息影响远大于 30 天前的产品好消息!
```

### 解决方案：时间加权

```
✅ 时间加权:
- 越新的消息权重越高
- 重大事件影响更深远
- 过期消息权重自动衰减
```

---

## 📊 三大核心机制

### 1. 时间衰减 (Time Decay)

**半衰期概念：**
- 默认**7 天**半衰期
- 7 天后影响力减半
- 14 天后只剩 25%
- 30 天后只剩 5%

**公式：**
```
时间权重 = 0.5 ^ (天数 / 半衰期)
```

**示例：**
| 时间 | 权重 | 解读 |
|------|------|------|
| 当天 | 1.00 | 100% 影响 |
| 3 天 | 0.74 | 74% 影响 |
| 7 天 | 0.50 | 50% 影响 (半衰期) |
| 14 天 | 0.25 | 25% 影响 |
| 30 天 | 0.05 | 5% 影响 (基本忽略) |

---

### 2. 事件影响力 (Event Impact)

**根据内容判断事件重要性：**

| 事件类型 | 关键词 | 权重 |
|---------|--------|------|
| **重大事件** | 裁员、并购、重组、退市、违法、调查、战略、突破、危机 | ×2.0 |
| **中等事件** | 业绩、订单、合同、新品、合作、高管、离职 | ×1.3 |
| **普通事件** | 日常经营、常规公告 | ×1.0 |

**示例：**
```
"公司裁员" → 重大事件 → 权重 ×2.0
"产品大卖" → 普通事件 → 权重 ×1.0
"业绩不及预期" → 中等事件 → 权重 ×1.3
```

---

### 3. 新鲜度奖励 (Freshness Bonus)

**24 小时内的新消息有额外奖励：**

| 时间 | 新鲜度奖励 |
|------|-----------|
| 0-6 小时 | ×1.5 |
| 6-12 小时 | ×1.3 |
| 12-24 小时 | ×1.1 |
| >24 小时 | ×1.0 (无奖励) |

---

## 🔢 综合权重计算

**最终权重 = 时间权重 × 影响力权重 × 新鲜度奖励**

### 示例计算

```
消息："听说公司最近裁员了"
时间：1 天前
可靠性：high
原始情感得分：0.234 (负面)

计算:
1. 时间权重 = 0.5 ^ (1/7) = 0.906
2. 影响力权重 = 2.0 (重大事件"裁员")
3. 新鲜度奖励 = 1.0 (超过 6 小时)

最终权重 = 0.906 × 2.0 × 1.0 = 1.811

加权得分 = 0.234 × 1.811 = 0.424
```

对比另一条旧消息：

```
消息："产品大卖 哈哈"
时间：10 天前
可靠性：low
原始情感得分：0.856 (正面)

计算:
1. 时间权重 = 0.5 ^ (10/7) = 0.371
2. 影响力权重 = 0.8 (可靠性低)
3. 新鲜度奖励 = 1.0

最终权重 = 0.371 × 0.8 × 1.0 = 0.297

加权得分 = 0.856 × 0.297 = 0.254
```

**结论:**
- 虽然"产品大卖"原始得分高 (0.856)
- 但因为是旧消息且可靠性低，加权后影响很小 (0.254)
- "裁员"虽然也是负面，但因为新且重要，影响很大 (0.424)

## 🎯 实际运行示例

```python
from src.analysis.time_weighted_sentiment import TimeWeightedSentiment

analyzer = TimeWeightedSentiment(half_life_days=7.0)

# 输入消息 (包含时间戳)
items = [
    {
        'content': '听说公司最近裁员了',
        'created_at': '2026-05-09 10:00:00',
        'sentiment': {'score': 0.234},  # 负面
        'reliability': 'high',
        'tags': ['财务']
    },
    {
        'content': '供应商说订单减少了',
        'created_at': '2026-05-07 14:00:00',
        'sentiment': {'score': 0.312},  # 负面
        'reliability': 'medium'
    },
    {
        'content': '产品大卖 哈哈',
        'created_at': '2026-04-30 09:00:00',
        'sentiment': {'score': 0.856},  # 正面
        'reliability': 'low'
    },
    {
        'content': '公司重大战略转型 AI',
        'created_at': '2026-05-08 16:00:00',
        'sentiment': {'score': 0.789},  # 正面
        'reliability': 'high',
        'tags': ['战略', 'AI']
    }
]

# 分析
result = analyzer.calculate_weighted_sentiment(items)

print(f"原始情绪得分：{result['raw_score']}")
print(f"加权情绪得分：{result['weighted_score']}")
print(f"差异：{result['difference']}")
print(f"解读：{result['explanation']}")
```

**输出：**
```
原始情绪得分：0.563
加权情绪得分：0.483
差异：-0.079 (权重偏向负面消息)

解读:
  加权后得分 < 原始得分
  说明近期或重大事件偏向负面
  需要特别关注这些负面信号
```

## 📊 不同半衰期的影响

### 测试对比

| 半衰期 | 加权得分 | 原始得分 | 差异 | 适用场景 |
|--------|---------|---------|------|---------|
| 3 天 | 0.456 | 0.563 | -0.107 | 短线交易 (非常敏感) |
| 7 天 | 0.483 | 0.563 | -0.079 | 中线投资 (推荐) |
| 14 天 | 0.501 | 0.563 | -0.062 | 长线投资 (较稳定) |
| 30 天 | 0.512 | 0.563 | -0.050 | 价值投资 (很稳定) |

### 如何选择半衰期？

| 投资风格 | 建议半衰期 | 特点 |
|---------|----------|------|
| **超短线** (1-3 天) | 1-3 天 | 对最新消息极度敏感 |
| **短线** (1-2 周) | 3-7 天 | 平衡敏感性和稳定性 |
| **中线** (1-3 月) | 7-14 天 | **推荐**,适用于大多数情况 |
| **长线** (3 月+) | 14-30 天 | 过滤短期噪音 |

## ⚠️ 注意事项

### 1. 半衰期不是绝对的

- **行业差异**: 科技行业变化快，半衰期应更短 (3-5 天)
- **行业差异**: 传统行业变化慢，半衰期可更长 (10-14 天)
- **市场环境**: 震荡市半衰期短，趋势市半衰期长

### 2. 重大事件识别有限

- 基于关键词判断，可能有误判
- 某些隐性重大事件可能识别不到
- 建议人工复核极端差异

### 3. 时间权重不改变原始得分

- 只是调整权重，不改变情感本身
- 过期消息仍然保留，只是权重低
- 方便后续回溯和复盘

```python
# 中线投资 (推荐)
analyzer = TimeWeightedSentiment(half_life_days=7.0)

# 每周运行一次

# 对比上周
if result['weighted_score'] > last_week['weighted_score'] + 0.1:
    print("情绪明显好转")
elif result['weighted_score'] < last_week['weighted_score'] - 0.1:
    print("情绪明显恶化")
else:
    print("情绪稳定")
```

### 对比分析

```python
# 不同半衰期对比
for half_life in [3, 7, 14]:
    analyzer = TimeWeightedSentiment(half_life_days=half_life)
    result = analyzer.calculate_weighted_sentiment(items)

# 如果不同半衰期都指向同一方向 → 信号更可靠
```
