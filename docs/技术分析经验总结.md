# 股票技术分析经验总结

> 基于 Phase 2 实战经验 | 2026-05-10

---

## 📌 核心原则

### 1. 没有万能指标

> ⚠️ **任何单一指标都有局限性，必须综合判断**

| 指标 | 擅长场景 | 失效场景 |
|------|---------|---------|
| MACD | 趋势行情 | 横盘震荡 |
| RSI | 超买超卖判断 | 强者恒强/弱者恒弱 |
| 布林带 | 震荡行情 | 单边突破行情 |
| 均线 | 趋势跟踪 | 频繁交叉的震荡市 |

**经验：** 至少结合 2-3 个指标，信号一致时可靠性更高

---

### 2. 指标是滞后工具

> ⚠️ **所有指标都是根据历史数据计算的，不是预测未来**

- 价格先变 → 指标后变
- 指标发出信号时，行情可能已经走了一半
- 不要指望指标能买在最低点、卖在最高点

**经验：** 指标用来确认趋势，不是预测趋势

---

### 3. 周期很重要

> ⚠️ **同一只股票，不同周期看可能得出相反结论**

| 周期 | 用途 | 特点 |
|------|------|------|
| 日线 | 中线操作 | 最常用，信号稳定 |
| 周线 | 长线趋势 | 信号少但可靠 |
| 60 分钟 | 短线操作 | 信号多但假信号也多 |

**经验：** 先看大周期定方向，再看小周期找买卖点

## 📊 各指标使用心得

### MACD (异同移动平均线)

**最适合：** 趋势行情

**实战经验：**

| 情况 | 可靠性 | 操作建议 |
|------|--------|---------|
| 零轴上方金叉 | ⭐⭐⭐⭐⭐ | 强烈买入信号 |
| 零轴下方金叉 | ⭐⭐⭐ | 可能是反弹，小心 |
| 零轴上方死叉 | ⭐⭐⭐ | 可能是回调，观察 |
| 零轴下方死叉 | ⭐⭐⭐⭐⭐ | 强烈卖出信号 |
| 背离 (价格新高但 MACD 不新高) | ⭐⭐⭐⭐ | 趋势可能反转 |

**平安银行案例：**
```
2026-04-17 MACD 死叉 → 之后确实回调
当前状态：DIF > DEA，多头，但力度不强
```

**深信服案例：**
```
2026-04-08 MACD 金叉 → 之后大涨到 180
当前状态：DIF > DEA，多头趋势明显
```

**注意事项：**
- 横盘时 MACD 会频繁金叉死叉，不要用
- 结合零轴位置判断 (零轴上方更可靠)
- 背离信号比金叉死叉更有价值

---

### RSI (相对强弱指标)

**最适合：** 判断超买超卖

**实战经验：**

| RSI 数值 | 含义 | 可靠性 | 操作 |
|---------|------|--------|------|
| > 80 | 严重超买 | ⭐⭐⭐⭐ | 坚决不追高 |
| 70-80 | 超买 | ⭐⭐⭐ | 考虑减仓 |
| 50-70 | 强势区 | ⭐⭐ | 持有 |
| 30-50 | 弱势区 | ⭐⭐ | 观望 |
| 20-30 | 超卖 | ⭐⭐⭐ | 可考虑建仓 |
| < 20 | 严重超卖 | ⭐⭐⭐⭐ | 可大胆买入 |

**平安银行案例：**
```
当前 RSI = 53.91 → 正常区域，不高不低
2026-04-13 RSI 超买 → 之后确实回调
```

**深信服案例：**
```
当前 RSI = 69.52 → 接近超买，要小心
2026-04-03 RSI 超卖 → 之后反弹
```

**注意事项：**
- 强势股可能长期在超买区 (RSI>70)
- 弱势股可能长期在超卖区 (RSI<30)
- RSI 背离比绝对值更有意义

---

### 布林带 (Bollinger Bands)

**最适合：** 震荡行情

**实战经验：**

| 价格位置 | 含义 | 可靠性 | 操作 |
|---------|------|--------|------|
| 突破上轨 | 超买 | ⭐⭐⭐ | 不追高，可能回调 |
| 贴近上轨 | 强势 | ⭐⭐ | 持有但设止损 |
| 中轨附近 | 正常 | ⭐⭐ | 观望，等方向 |
| 贴近下轨 | 弱势 | ⭐⭐ | 持有但小心 |
| 突破下轨 | 超卖 | ⭐⭐⭐ | 不杀跌，可能反弹 |
| 通道收窄 | 变盘前兆 | ⭐⭐⭐⭐ | 准备迎接大行情 |

**平安银行案例：**
```
2026-04-27~29 连续 3 天触及上轨 → 之后回调
当前价格 11.30，在通道中部，正常
```

**深信服案例：**
```
2026-05-06 触及上轨 125.60 → 之后回调到 123.52
当前价格接近上轨，要小心
```

**注意事项：**
- 单边行情中，价格可能沿上轨/下轨一直走
- 通道收窄后必有大行情 (但不一定是哪个方向)
- 结合成交量判断突破真假

---

### 均线 (Moving Average)

**最适合：** 趋势跟踪

**实战经验：**

| 均线组合 | 含义 | 可靠性 | 操作 |
|---------|------|--------|------|
| 价格>MA5>MA10>MA20 | 多头排列 | ⭐⭐⭐⭐⭐ | 坚决做多 |
| 价格<MA5<MA10<MA20 | 空头排列 | ⭐⭐⭐⭐⭐ | 坚决做空 |
| MA5 上穿 MA10 | 短期金叉 | ⭐⭐⭐ | 短线买入 |
| MA5 下穿 MA10 | 短期死叉 | ⭐⭐⭐ | 短线卖出 |
| 价格在均线上方 | 均线支撑 | ⭐⭐⭐ | 回调可买 |
| 价格在均线下方 | 均线压力 | ⭐⭐⭐ | 反弹要卖 |

**平安银行案例：**
```
当前：价格 11.30，MA5=11.38，MA20=11.20
价格在中短期均线之间，方向不明
```

**深信服案例：**
```
当前：价格 123.52，MA5=120.89，MA10=115.90，MA20=112.82
价格>MA5>MA10>MA20，多头排列，趋势向好
```

**注意事项：**
- 震荡市均线会频繁交叉，失效
- 长期均线 (MA60/MA120) 更可靠但滞后
- 均线密集后发散往往是大行情开始

## 🎯 综合分析框架

### 步骤 1: 看大趋势

```
1. 价格在长期均线 (MA60) 上方还是下方？
2. MACD 在零轴上方还是下方？
3. 周线级别是什么趋势？
```

**判断：** 多头市场只做多，空头市场只做空

---

### 步骤 2: 找买卖点

```
多头市场中：
- RSI < 30 → 买入机会
- 价格触及布林带下轨 → 买入机会
- MACD 金叉 → 加仓信号

空头市场中：
- RSI > 70 → 卖出机会
- 价格触及布林带上轨 → 卖出机会
- MACD 死叉 → 减仓信号
```

---

### 步骤 3: 验证信号

```
单一信号 → 不可靠
两指标共振 → 较可靠
三指标共振 → 很可靠

例如：
✅ RSI 超卖 + 触及布林带下轨 + MACD 金叉 = 强烈买入信号
❌ 只有 RSI 超卖 = 再等等
```

---

### 步骤 4: 设止损位

```
买入后必须设止损：
- 短线：跌破 MA5 或 MA10
- 中线：跌破 MA20 或布林带下轨
- 长线：跌破 MA60

止损幅度：一般 5-10%
```

## 📈 实战案例分析

### 案例 1: 深信服 (300454) - 2026 年 4 月

**背景：** 经历一波下跌后企稳

**买入信号 (2026-04-03 ~ 04-08)：**
```
✅ RSI 超卖 (<30)
✅ MACD 金叉
✅ 价格触及布林带下轨
✅ 三指标共振
```

**结果：** 从 95 块涨到 180 块，涨幅 89%

**卖出信号 (2026-01 ~ 02 月)：**
```
✅ RSI 超买 (>80)
✅ MACD 死叉
✅ 价格跌破 MA20
```

**结果：** 从 180 块跌到 100 块，跌幅 44%

**经验：**
1. 三指标共振时可靠性极高
2. 超卖后可能还有超卖，要等 MACD 金叉确认
3. 大级别背离是重要反转信号

---

### 案例 2: 平安银行 (000001) - 2026 年 4 月

**背景：** 横盘震荡

**特点：**
```
- MACD 频繁金叉死叉 (失效)
- RSI 在 40-70 之间波动
- 布林带收窄，通道震荡
```

**有效信号：**
```
2026-04-27~29 连续 3 天触及布林带上轨 → 回调
```

**经验：**
1. 震荡市 MACD 不好用
2. 布林带在震荡市很有效
3. 同一信号多次出现后可靠性下降

## ⚠️ 常见错误总结

### 错误 1: 只看一个指标

```
❌ 看到 RSI 超卖就买入 → 可能继续超卖
✅ 等 MACD 金叉确认后再买
```

### 错误 2: 逆势操作

```
❌ 空头市场看到 RSI 超卖就抄底 → 可能抄在半山腰
✅ 空头市场只做反弹，快进快出
```

### 错误 3: 不看成交量

```
❌ 价格突破就追 → 可能是假突破
✅ 突破必须放量才可靠
```

### 错误 4: 不止损

```
❌ 指望跌了还会涨回来 → 可能越套越深
✅ 设定止损位，跌破就走
```

### 错误 5: 频繁交易

```
❌ 看到信号就做 → 手续费都不够
✅ 只做高确定性机会 (三指标共振)
```

## 📝 交易纪律

### 买入条件 (必须满足 3 个以上)

- [ ] 大趋势是多头 (价格>MA60，MACD 零轴上方)
- [ ] RSI 超卖或从低位拐头向上
- [ ] MACD 金叉或绿柱缩短
- [ ] 价格触及布林带下轨后反弹
- [ ] 成交量放大
- [ ] 有明确的催化剂 (业绩/政策/消息)

### 卖出条件 (满足 1 个即可)

- [ ] 跌破止损位 (5-10%)
- [ ] RSI 超买 (>70)
- [ ] MACD 死叉
- [ ] 价格触及布林带上轨后回落
- [ ] 趋势破坏 (跌破关键均线)
- [ ] 达到目标价位

### 仓位管理

| 信号强度 | 仓位 | 说明 |
|---------|------|------|
| 一指标信号 | 0-10% | 观察仓位，试试水 |
| 两指标共振 | 30-50% | 常规仓位 |
| 三指标共振 | 70-100% | 重仓出击 |
| 不确定 | 空仓 | 宁可错过，不要做错 |

## 💡 进阶技巧

### 1. 背离判断

**顶背离：** 价格创新高，指标不创新高 → 看跌
**底背离：** 价格创新低，指标不创新低 → 看涨

```
背离的可靠性排序：
MACD 背离 > RSI 背离 > 均线背离
周线背离 > 日线背离 > 分钟线背离
```

### 2. 多周期共振

```
日线多头 + 周线多头 + 月线多头 = 大牛市
日线空头 + 周线空头 + 月线空头 = 大熊市

操作原则：
- 顺大周期，逆小周期
- 周线多头时，日线回调是买入机会
```

### 3. 量价关系

| 价格 | 成交量 | 含义 | 操作 |
|------|--------|------|------|
| 上涨 | 放量 | 健康上涨 | 持有 |
| 上涨 | 缩量 | 可能见顶 | 减仓 |
| 下跌 | 放量 | 恐慌下跌 | 不接 |
| 下跌 | 缩量 | 正常回调 | 观察 |

## ⚠️ 风险提醒

1. **技术分析不是万能的** - 还要看基本面、消息面
2. **过去不代表未来** - 历史走势仅供参考
3. **市场永远是对的** - 错了要认，及时止损
4. **不要用杠杆** - 新手死于追高，老手死于抄底，高手死于杠杆
5. **闲钱投资** - 不要借钱炒股，不要卖房炒股
