# 个人投资记忆库使用指南

> 版本：v1.0 | 更新时间：2026-05-10

---

## 🎯 功能概述

**个人投资记忆库**允许你：

1. **记录小道消息** - 来自员工、供应商、论坛等的消息
2. **记录个人观察** - 对产品、竞争、管理层的观察
3. **追踪疑问** - 有待验证的问题
4. **记录决策** - 买卖决策及理由
5. **持续分析** - 情绪趋势、可靠性评估

---

## 🚀 快速开始

### 1. 启动记忆库

```bash
cd /workspace/stock-analyzer
python3 src/analysis/memory_bank.py 300454
```

### 2. 基本命令

```
obs <内容> [tags]          - 添加个人观察
rumor <内容> [来源] [可靠性] - 添加小道消息
q <问题>                    - 添加疑问
dec <决策> <理由>           - 添加决策
list [类型]                 - 列出记录
report                      - 生成分析报告
trend                       - 分析情绪趋势
exit                        - 退出
```

## 💡 最佳实践

### 1. 可靠性评估

| 来源 | 建议可靠性 | 说明 |
|------|----------|------|
| 内部员工 | high | 相对可靠，但可能有偏见 |
| 供应商/客户 | high | 业务往来，信息真实 |
| 行业分析师 | medium | 专业但可能有利益冲突 |
| 雪球/论坛 | low | 真伪难辨，仅供参考 |
| 微博/社交媒体 | low | 谣言多，需谨慎 |

### 2. 标签建议

常用标签：
- `产品` - 产品相关
- `竞争` - 竞争对手动态
- `市场` - 市场变化
- `管理层` - 高管变动
- `财务` - 财务数据
- `战略` - 公司战略
- `技术` - 技术突破
- `政策` - 政策影响

### 3. 定期回顾

**每周回顾:**
```
> list obs        # 看本周观察
> trend           # 看情绪趋势
```

**每月报告:**
```
> report          # 生成完整报告
```

**投资决策前:**
```
> list rumor high    # 看高可靠性消息
> list dec           # 看历史决策
```

## 🔧 高级用法

### 1. Python API 调用

```python
from src.analysis.memory_bank import MemoryBank

# 创建记忆库
memory = MemoryBank("300454")

# 添加观察
memory.add_observation(
    "公司新发布的 AI 产品很受欢迎",
    tags=['产品', 'AI'],
    sentiment_analysis=True
)

# 添加小道消息
memory.add_rumor(
    "听说要裁员",
    source="员工",
    reliability="high"
)

# 查看情绪趋势
trend = memory.analyze_trend()
print(f"趋势：{trend['trend_cn']}")

# 生成报告
report = memory.generate_report()
with open(f"{memory.symbol}_memory_report.txt", 'w') as f:
    f.write(report)
```

### 2. 批量导入

```python
memory = MemoryBank("300454")

# 批量导入观察
observations = [
    ("产品很受欢迎", ['产品']),
    ("竞争对手降价", ['竞争']),
]

for content, tags in observations:
    memory.add_observation(content, tags)
```

## 📁 文件存储

每个股票的记忆库保存为：
```
memory_<股票代码>.json
```

例如：
```
memory_300454.json
memory_000001.json
```

**JSON 结构:**
```json
{
  "symbol": "300454",
  "created_at": "2026-05-10 15:30:00",
  "updated_at": "2026-05-10 15:30:45",
  "observations": [...],
  "rumors": [...],
  "questions": [...],
  "decisions": [...],
  "analysis_history": [...]
}
```
