## 📊 回测参数说明

```python
backtest_with_real_news(
    symbol='300454',        # 股票代码
    start_date='2025-11-01', # 开始日期
    end_date='2026-05-10',   # 结束日期
    half_life_days=7.0,      # 半衰期 (天)
    buy_threshold=0.35,      # 买入阈值 (情绪<0.35)
    sell_threshold=0.65,     # 卖出阈值 (情绪>0.65)
    initial_capital=100000   # 初始资金
)
```

**参数推荐：**

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| half_life_days | 7 | 7 天半衰期，适合中线 |
| buy_threshold | 0.35 | 情绪极低时买入 |
| sell_threshold | 0.65 | 情绪极高时卖出 |
| start_date | 6 个月前 | 回测周期建议 6 个月以上 |

## 💡 常见问题

### Q1: 登录失败

```
❌ 聚宽登录失败：Invalid credentials
```

**解决：**
- 检查账号密码是否正确
- 确认已注册聚宽账号
- 尝试在聚宽官网登录验证

---

### Q2: 获取不到新闻

```
⚠️ 未获取到新闻数据
```

**原因：**
- 聚宽免费账号只有有限的新闻数据
- 某些股票历史新闻较少

**解决：**
- 换一个股票试试 (如 000001 平安银行)
- 缩短回测时间范围
- 使用多个股票测试

---

### Q3: 回测胜率低

```
买入胜率：42%
卖出胜率：38%
```

**分析：**
1. **参数问题** - 阈值设置不合理
   - 尝试调整 buy_threshold 和 sell_threshold
   
2. **股票问题** - 该股票不适用情绪策略
   - 换几只股票测试
   
3. **周期问题** - 回测周期太短
   - 延长到 6-12 个月

## 📊 多股票批量回测

```python
symbols = ['300454', '000001', '600519', '000858']

all_results = {}

for symbol in symbols:
    result = backtester.backtest_with_real_news(
        symbol=symbol,
        start_date='2025-11-01',
        end_date='2026-05-10'
    )
    all_results[symbol] = result

# 对比结果
print("股票\t买入胜率\t卖出胜率")
for symbol, result in all_results.items():
    print(f"{symbol}\t{result['buy_win_rate']:.1f}%\t\t{result['sell_win_rate']:.1f}%")
```

## 📝 重要提醒

1. **聚宽免费限制**
   - 每天有调用次数限制
   - 历史数据可能不完整
   - 仅用于学习验证

2. **回测不等于实盘**
   - 回测有效 ≠ 实盘一定赚钱
   - 需要小资金验证
   - 做好风险控制

3. **数据来源说明**
   - 聚宽的新闻来自各大财经网站
   - 质量较好，但可能有延迟
   - 适合日线级别回测
