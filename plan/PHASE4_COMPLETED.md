## 技术实现

### 模块结构

```
src/ml/
├── __init__.py
├── features.py          # 特征工程
├── models.py            # 模型训练和预测
├── evaluator.py         # 模型评估
├── visualizer.py        # 预测结果可视化
└── predictor.py         # 主程序入口
```

### 特征工程 (features.py)

生成 54 个特征，包括：

| 类别 | 特征 | 数量 |
|------|------|------|
| 技术指标 | MA, MACD, RSI, 布林带 | ~15 |
| 价格形态 | 振幅、实体、影线 | ~8 |
| 成交量 | 量比、量价相关性 | ~8 |
| 时间特征 | 星期、月份、季度 | ~5 |
| 动量 | 多周期收益率、价格位置 | ~10 |
| 波动率 | 历史波动率、ATR | ~8 |

### 支持的模型 (models.py)

| 模型 | 分类 | 回归 | 说明 |
|------|------|------|------|
| RF (随机森林) | ✅ | ✅ | 默认推荐，支持特征重要性 |
| GB (梯度提升) | ✅ | ✅ | 精度高，训练稍慢 |
| SVM | ✅ | ✅ | 适合小样本 |
| LR (逻辑回归) | ✅ | ✅ | 基线模型，速度快 |

### 可视化 (visualizer.py)

- 涨跌预测准确率趋势图
- 特征重要性条形图
- 混淆矩阵热力图

## 使用方法

### 训练模型

```bash
# 使用默认随机森林模型
python3 src/ml/predictor.py 300454 --train

# 使用梯度提升模型
python3 src/ml/predictor.py 300454 --train --model gb

# 回归任务（预测涨跌幅）
python3 src/ml/predictor.py 300454 --train --task regress
```

### 预测走势

```bash
# 分类预测（涨/跌）
python3 src/ml/predictor.py 300454 --predict

# 回归预测（涨跌幅）
python3 src/ml/predictor.py 300454 --predict --task regress
```

### 运行测试

```bash
python3 src/ml/predictor.py --test
```

## 注意事项

1. **数据量要求**: 至少需要 200 个交易日数据
2. **时间序列分割**: 训练/测试集按时间顺序分割，避免数据泄露
3. **过拟合风险**: 股票预测本身具有随机性，模型仅供参考
4. **模型更新**: 建议定期用最新数据重新训练
