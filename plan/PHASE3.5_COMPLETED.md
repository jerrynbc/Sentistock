# Phase 3.5 完成 - 个人投资记忆库

> 完成时间：2026-05-10

---

## 🎯 功能概述

**个人投资记忆库**实现了：

1. ✅ **小道消息收集** - 记录来自各种渠道的消息
2. ✅ **个人观察记录** - 记录你对公司/行业的观察
3. ✅ **疑问追踪** - 记录待验证的问题
4. ✅ **决策日志** - 记录投资决策及理由
5. ✅ **情绪分析** - 自动分析每条信息的情感倾向
6. ✅ **趋势分析** - 分析情绪变化趋势
7. ✅ **持久化存储** - JSON 文件保存，可持续积累
8. ✅ **报告生成** - 定期生成分析报告

---

##  使用方法

### 1. 启动记忆库

```bash
cd /workspace/stock-analyzer
python3 src/analysis/memory_bank.py <股票代码>

# 示例
python3 src/analysis/memory_bank.py 300454
```

### 2. 基本命令

| 命令 | 说明 | 示例 |
|------|------|------|
| `obs <内容> [tags]` | 添加个人观察 | `obs 产品大卖 [产品]` |
| `rumor <内容> [来源] [可靠性]` | 添加小道消息 | `rumor 要裁员了 员工 high` |
| `q <问题>` | 添加疑问 | `q 为什么高管离职？` |
| `dec <决策> <理由>` | 添加决策 | `dec 减仓 10% 消息面不好` |
| `list [类型]` | 列出记录 | `list`, `list rumor`, `list obs` |
| `trend` | 分析情绪趋势 | `trend` |
| `report` | 生成完整报告 | `report` |
| `exit` | 退出 | `exit` |

## 💡 最佳实践

### 可靠性评估标准

| 来源 | 建议可靠性 | 说明 |
|------|----------|------|
| 内部员工 | **high** | 相对可靠，但可能有个人偏见 |
| 供应商/客户 | **high** | 业务往来，信息较真实 |
| 行业分析师 | **medium** | 专业但可能有利益冲突 |
| 雪球/论坛 | **low** | 真伪难辨，仅供参考 |
| 微博/朋友圈 | **low** | 谣言多，需谨慎 |

### 常用标签

- `产品` - 产品动态
- `竞争` - 竞争对手
- `市场` - 市场变化
- `管理层` - 高管变动
- `财务` - 财务数据
- `战略` - 公司战略
- `技术` - 技术突破
- `政策` - 政策影响
- `舆情` - 市场舆情

### 使用频率建议

| 时间 | 建议操作 |
|------|---------|
| 每天 | 记录看到的小道消息、观察 |
| 每周 | `list` 查看本周记录，`trend` 看趋势 |
| 每月 | `report` 生成完整报告，复盘决策 |
| 决策前 | 回顾历史记录，避免重复错误 |

## 🔧 Python API 使用

```python
from src.analysis.memory_bank import MemoryBank

# 创建记忆库
memory = MemoryBank("300454")

# 添加观察
memory.add_observation(
    "产品大卖",
    tags=['产品'],
    sentiment_analysis=True
)

# 添加小道消息
memory.add_rumor(
    "听说要裁员",
    source="员工",
    reliability="high"
)

# 添加疑问
memory.add_question("为什么高管离职？")

# 添加决策
memory.add_decision(
    "减仓 10%",
    "消息面不好"
)

# 查看所有记录
print(memory.list_all())

# 分析情绪趋势
trend = memory.analyze_trend()
print(f"趋势：{trend['trend_cn']}")
print(f"解释：{trend['explanation']}")

# 生成报告
report = memory.generate_report()
with open('report.txt', 'w') as f:
    f.write(report)
```

## ⚠️ 注意事项

### 1. 消息验证

- ⚠️ 小道消息**不保证真实性**
- ✅ 高可靠性消息也需要验证
- ✅ 后续可以通过 `verified` 字段标记验证结果

### 2. 情绪分析准确性

- 自动情感分析可能有误差
- 特别是反讽、双关等复杂语义
- 建议人工复核极端得分

### 3. 数据安全

- 记忆库文件存储在本地
- 包含你的投资思路和决策
- 建议定期备份
