## 情感分析原理

### SnowNLP 情感打分

SnowNLP 是一个中文自然语言处理库，情感分析基于贝叶斯分类器。

```
输入文本 → 分词 → 特征提取 → 分类器 → 情感得分 (0-1)

得分解释:
- 0.0 - 0.4: 负面 (红色)
- 0.4 - 0.6: 中性 (灰色)
- 0.6 - 1.0: 正面 (绿色)
```

### 情绪指数计算

```python
整体得分 = 所有新闻情感得分的平均值

情绪等级:
- > 0.7: 非常乐观
- 0.55-0.7: 谨慎乐观
- 0.45-0.55: 中性
- 0.3-0.45: 谨慎悲观
- < 0.3: 非常悲观
```

### 相关性分析

```
皮尔逊相关系数:
- > 0.5: 强正相关 (情绪好时价格上涨)
- 0.2-0.5: 弱正相关
- -0.2-0.2: 无相关
- -0.5~-0.2: 弱负相关
- < -0.5: 强负相关 (情绪好时价格下跌)
```

## 情绪分析的意义

### 为什么情绪会影响股价？

1. **投资者心理** - 乐观情绪导致买入，悲观情绪导致卖出
2. **羊群效应** - 多数人看好时，其他人会跟随
3. **媒体放大** - 负面新闻会被放大传播
4. **预期自我实现** - 大家都认为会涨，真的就涨了

### 实际应用场景

| 场景 | 情绪指标 | 操作建议 |
|------|---------|---------|
| 情绪极度悲观 | < 0.3 | 可能是买入机会 (别人恐惧我贪婪) |
| 情绪极度乐观 | > 0.8 | 可能是卖出信号 (别人贪婪我恐惧) |
| 情绪与价格背离 | 情绪好但价格跌 | 可能是错杀，关注 |
| 情绪快速转好 | 上升中 | 可能还有上涨空间 |

### 关键词提取

使用 TF-IDF 算法提取关键词：
- TF (词频): 词在文档中出现次数
- IDF (逆文档频率): 词的区分度
- TF-IDF = TF × IDF
